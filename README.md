
# Job & Internship Tracker

A full-stack web application to manage job and internship applications and organize career-related tasks.

## Features
- User registration and login
- Add and manage job and internship applications
- Track application statuses
- Create tasks and mark them as completed
- Dashboard to view applications and pending tasks

## Tech Stack
- **Frontend:** React.js, JavaScript, CSS, Vite
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/swastika-paul/ai-job-internship-tracker.git
cd ai-job-internship-tracker
```

### 2. Start the backend
```bash
cd backend
npm install
```

Create a `.env` file with your required environment variables, then start the backend using the script defined in `backend/package.json`.

### 3. Start the frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```
